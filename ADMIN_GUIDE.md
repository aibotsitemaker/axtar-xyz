# Admin təlimatı

v5-dəki istifadəçi, forum, kateqoriya, şikayət, məzmun və audit bölmələri saxlanılıb. `/admin/verification` müraciətlərə qərar vermək, `/admin/reviews` müəllim rəylərini moderasiya etmək üçündür. Əsas dashboard v6 cəmlərini də göstərir. Doğrulama qərarları serverdə icazə yoxlanışı və status dəyişmə trigger-i ilə işləyir. Admin rolunu brauzerdən və ya profil redaktəsindən heç vaxt verməyin.
