# Admin təlimatı

v5-də mövcud admin paneli istifadəçi, forum, kateqoriya, şikayət, məzmun və audit bölmələrini saxlayır. Mövcud 07/08 icazələrini dəyişməyin. V6 əlavə cədvəllərini yalnız admin hesabı ilə nəzərdən keçirin; brauzerdən istifadəçilərə admin rolunu verməyin. Feed moderasiyası üçün yazını gizlədin və ya silin. Doğrulama müraciətləri üçün server tərəfli admin əməliyyatı tətbiq edilməyənədək Supabase-də auditli admin icra etməlidir.
